# Explicit OAuth identity for share receipt

The user selected explicit `--auth-mode oauth` with the selected profile; without it, receipt remains anonymous and reads no account configuration or credentials. Apply this consistently to inspect, files and download. Reuse existing auth login/status, stored/environment token selection, coordinated refresh and service error handling. The service determines whether the selected recipient identity satisfies RequireLogin and all other share policies. OAuth never substitutes for a required extraction code.

Follow the current V1 SDK: OAuth authenticates public share metadata and GetShareAccessToken; after exchange, share-file requests use only x-share-token and signed content transfers remain credential-free. Reuse the account client's bounded share transport for the two public endpoints. OAuth API requests use the trusted selected profile API endpoint or explicit --endpoint, never an arbitrary origin copied from a public URL. Known standard IDS instance labels must agree with stored OAuth instance binding; custom page URLs remain identifiers while the configured service validates share ownership/scope. Do not start device login implicitly, fall back to another profile/identity, or persist share access tokens/passwords.

Keep Describe and dry-run free of config/credential/network I/O. Preserve one-page files --limit/--marker behavior, hidden terminal password prompting and explicit stdin/URL pwd sources. Download resume must retain API origin and authentication mode/profile identity without storing secrets so a change in receiver context cannot silently resume a different operation.

Expose the explicit auth mode in typed MCP/Skill inputs and update bilingual help, Describe/capability semantics, README, workflows and tests. Cover anonymous isolation, profile selection, logged-in receipt, expired/missing identity, wrong instance, password coexistence, token/header separation, non-replayed unknown exchanges, authenticated pagination/download/resume, redaction and both entrypoints.
